Cube Controls

Custom Function

Custom Mood sends the single character C and blanks/stops the cube.
Send Function sends @expressionE. @ starts reception and E ends reception. No newline is sent and E does not compile the function.
Run Animation sends the single character R. R compiles the stored function and starts it only if compilation succeeds.
Maximum function length: 192 characters. Maximum compiled bytecode: 80 instructions.
